# Rol de Procedimentos e Eventos em Saúde

O **Rol** é a lista de consultas, exames, cirurgias e tratamentos que os planos de saúde são obrigados a cobrir, conforme a segmentação contratada (ambulatorial, hospitalar com ou sem obstetrícia, referência ou odontológico). Vale para planos contratados a partir de 2 de janeiro de 1999 e para os adaptados à Lei nº 9.656/1998. Atualmente é estabelecido pela [RN nº 465/2021](../ans/01-resolucoes-normativas/RN-0465-2021.md) e suas alterações.

> Esta pasta é **atualizada automaticamente** sempre que a ANS publica nova versão dos anexos da RN nº 465/2021. As alterações também são registradas em [NOVIDADES.md](../NOVIDADES.md).
