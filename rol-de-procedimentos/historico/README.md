# Histórico de alterações do Rol (RN nº 465/2021)

Cada bloco corresponde a uma norma que gerou nova versão dos anexos da RN nº 465/2021. As listas são obtidas comparando automaticamente a versão anterior com a nova versão de cada anexo (mudanças apenas de redação no nome de um procedimento aparecem como exclusão + inclusão). Quando a ANS publica uma única nova versão de um anexo consolidando mais de uma norma, as mudanças aparecem na norma que a ANS registrou como responsável pela versão.

Veja também: [normas anteriores sobre o Rol (1998–2021)](normas-anteriores.md).
